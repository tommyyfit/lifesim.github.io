# LifeSim v24.2.1 Feature Summary

## Core game

- Life progression from birth through senior life
- Age-aware navigation, events and activities
- Education, careers, relationships, health, finances and family
- Optional skills, pets, social media, side work, business, investing and crime
- Achievements, memories, Hall of Fame and generational continuation
- Manual save, auto-save, backup, import and export

## Fun First interface

- Compact yearly command center
- Four suggested actions based on age and situation
- Recent moments and important people
- Clear Age Up call to action
- Optional systems separated from the main flow
- Simplified event decisions
- Responsive desktop and mobile layouts

## Settings

- Game feedback and auto-save
- Theme, accent, text and motion controls
- Sound and volume controls
- Optional local Ollama connection
- Save, import, export and recovery tools

## Ollama

- Disabled by default
- Local endpoint and model selection
- Connection testing and model discovery
- Built-in fallback when unavailable
- No authority over deterministic game rules
